# Ansible, Docker, & Kubernetes Learning Journey

This repository is my personal playground for learning **Ansible**, **Docker**, and **Kubernetes**.  
Here, I experiment with real-world scenarios, write playbooks, run containers, and deploy applications on clusters — all to better understand how these tools work together.

---

## What’s Inside

- **Ansible Playbooks**  
  Practical examples of installing software, configuring services, and automating tasks. Includes Docker installation playbooks and service management.

- **Docker Experiments**  
  Hands-on Docker setups, from creating images to running containers, and understanding networking and volumes.

- **Kubernetes Learning**  
  Small demos and practice clusters to explore pods, deployments, services, and cluster management.

---

## Why This Repository

I created this space to:

- Keep track of my learning journey  
- Experiment safely without breaking production systems  
- Share examples that are easy to understand for beginners
